# Inter-uni-datathon-credit-default
Probability-of-default model for the Inter-Uni Datathon, Stream 1. Calibrated gradient boosting, log loss 0.412.

# Stream 1 - Default of Credit Card Clients 

**Author:** Gousia  Ain, University of Sydney 
**Final leaderboard score:** 0.41200 (binary log loss)
**Final cross-validated score:** 0.42409, sd 0.0060 across 5 stratified folds
**Baseline (predicting the base rate for everyone):** 0.52843

## Reproducing the submission

1. Place `train.csv` and `test.csv` in the repository root, beside the notebook.
2. `pip install -r requirements.txt`
3. Open `INTER-UNI.ipynb` and run all cells top to bottom.
4. The final cell of **section 8** writes `submission_v5_final_seedavg.csv`.

Runtime is roughly 10–15 minutes on a laptop, most of it in the seed-averaging loop in
section 8 and the SHAP computation in section 10.

The notebook is strictly linear — every cell depends only on cells above it.

## Random seeds and settings

- `SEED = 42` applied to `random`, `numpy`, `PYTHONHASHSEED`, and the cross-validation split
- Cross-validation: `StratifiedKFold(n_splits=5, shuffle=True, random_state=42)`
- The final model averages over model seeds `[0, 1, 2]`
- All results are deterministic given these settings

---

## The final model

An equal-weight average of six fitted models — two families at three seeds each:

**LightGBM** — `n_estimators=400`, `learning_rate=0.03`, `num_leaves=15`,
`min_child_samples=80`, `subsample=0.8`, `subsample_freq=1`, `colsample_bytree=0.6`,
`reg_lambda=5.0`

**HistGradientBoostingClassifier** (scikit-learn) — `max_iter=400`, `learning_rate=0.03`,
`max_leaf_nodes=15`, `min_samples_leaf=80`, `l2_regularization=5.0`

Seeds: 0, 1, 2. Blend weights: equal, not optimised (see section 6 for why).

**Inputs:** the raw competition columns plus 18 engineered behavioural features, with
`SEX` removed following the ablation in section 7.

**Not used:** no class rebalancing (no SMOTE, no class weighting, no `scale_pos_weight`),
no post-hoc calibration, no pretrained models, no AutoML, no external data.

## Summary of results

| Model | CV log loss | sd |
|---|---|---|
| Constant (base rate) | 0.52843 | — |
| Logistic regression | 0.44514 | 0.0059 |
| LightGBM, raw features | 0.43211 | 0.0071 |
| LightGBM, + features, unregularised | 0.43296 | 0.0078 |
| LightGBM, regularised | 0.42557 | 0.0064 |
| HistGradientBoosting | 0.42524 | 0.0063 |
| Blend, 50/50 | 0.42446 | 0.0061 |
| **+ seed averaging (final)** | **0.42409** | **0.0060** |

Section 13 records the experiments that were tested and rejected, with the numbers behind
each decision.
